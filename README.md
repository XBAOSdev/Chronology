# 大事年表（Chronology）

> 一款**纯前端、离线可用**的历史时间轴工具。零第三方依赖，双击 `index.html` 即可运行。

面向高中历史学习与教学场景，提供中国史、世界史、经济史、文化史**四套内置时间轴**（共 **529** 条史实）。其中中国史、世界史按人教版高中历史必修《中外历史纲要》体系整理，**并向前延伸到约公元前 9000 年的农业革命与中华文明起源**；经济史、文化史作为专题史，分别参照选择性必修 2《经济与社会生活》、选择性必修 3《文化交流与传播》整理。支持缩放、折叠、聚合、检索、编辑与导入导出。

## 一、快速开始

### 方式 A：双击打开（推荐，完全离线）

直接双击项目根目录的 `index.html`，用 Chrome / Edge / Firefox 等现代浏览器打开即可。

> 项目刻意采用**普通 `<script>` 顺序加载 + 全局变量注册**的方式组织代码与数据，而非 ES Module + `fetch`，正是为了绕过浏览器在 `file://` 协议下对本地文件读取的限制，从而保证双击即可用。

### 方式 B：本地静态服务器

```bash
# 任选其一，在项目根目录执行
python -m http.server 8080
# 或
npx serve .
```

然后访问 `http://localhost:8080/`。

### 方式 C：静态托管（Cloudflare Pages 等）

本项目为**无构建的纯静态站点**，无需任何打包步骤：

1. 将整个目录推送到 Git 仓库，或在 Cloudflare Pages 中直接上传该目录；
2. 构建命令留空，输出目录设为根目录 `.`；
3. 完成部署即可访问。

因所有资源均为相对路径且不含服务端路由，GitHub Pages、Netlify、对象存储静态网站托管等同样适用。

## 二、功能总览

| 模块 | 说明 |
| --- | --- |
| **时间轴视图** | Canvas 2D 渲染，事件在时间轴上下交错分布，带引线与刻度 |
| **缩放 / 折叠** | 滚轮或捏合缩放；`Ctrl`+滚轮（或横向捏合）进行**横向折叠**，只压缩时间轴、不改变节点与文字大小 |
| **自动分级** | 依据当前缩放自动决定等级上限；**等级未达标的标签在确实空旷处仍会补显出来**（同一行放得下就正常显示，真正拥挤时才按等级顺序舍弃），因此远古史等稀疏区段不会只剩最高等级的事件。也可手动指定等级严格过滤 |
| **聚合节点** | 屏幕距离过近的事件自动合并显示数量，放大后自动拆分，**不丢数据** |
| **模糊检索** | 连续子串优先 + 子序列加权，支持跨字段匹配与结果高亮，键盘上下键导航 |
| **日期跳转** | 支持 `公元前221年`、`1949-10-01`、`19世纪60年代`、`1949年10月1日15时` 等多种写法定位 |
| **事件详情** | 点击节点查看详情卡，时间显示到数据的最精确精度；点击空白处即可关闭；聚合节点展开为事件列表 |
| **跨时间轴关联线** | 选中事件后用虚线连接其他时间轴上的同一事件（如抗日战争与第二次世界大战）；端点直接由事件数据与变换矩阵计算，与轨道顺序、缩放、折叠、聚合均无关，缩放平移时不会在不同事件之间跳动 |

| **编辑模式** | 可新增 / 修改 / 删除事件、拖动节点改时间、点击空白轨道在指定时间点新建事件；**系统内置时间轴只读，编辑时自动另存为用户副本** |

## 五、时间坐标模型（全项目唯一真源）

所有时间→屏幕坐标的换算统一由 `src/core/time-model.js` 提供：

| 真实时间 | 坐标 `x` |
| --- | --- |
| 公元 1 年 | `0` |
| 公元 n 年 | `n - 1` |
| 公元前 n 年 | `-n` |

月 / 日 / 时 / 分作为「年内小数」叠加在年份之上：

- 月：`+ (month - 1) / 12`
- 日：`+ (day - 1) / 365.25`
- 时：`+ hour / 8766`
- 分：`+ minute / 525960`

> 设计要点：公元 1 年与公元前 1 年连续（无「公元 0 年」断层）；公元前年份的小数部分**向公元元年方向递进**。

横向缩放与折叠分别作用于两个独立维度：

```
pxPerYear = BASE_PX_PER_YEAR(2) × zoom × fold
```

- `zoom` 同时影响横纵比例；`fold` **只压缩时间轴横向密度**，节点大小与文字保持不变。

## 六、数据格式

### 6.1 文件形态

单文件 = 单时间轴，JSON 格式，含 `schemaVersion`（当前为 `1`）。

```json
{
  "schemaVersion": 1,
  "id": "user-china-history-1726xxxxxxx",
  "title": "中国史（我的副本）",
  "subtitle": "中华文明发展脉络",
  "category": "中国史",
  "color": "#e0625a",
  "description": "……",
  "source": "user",
  "copyOf": "china-history",
  "exportedAt": "2026-09-10T02:26:32.000Z",
  "events": [
    {
      "id": "cn-1949",
      "timelineId": "user-china-history-1726xxxxxxx",
      "title": "中华人民共和国成立",
      "summary": "开国大典在北京天安门广场举行，中华人民共和国中央人民政府成立。",
      "date": {
        "year": 1949,
        "month": 10,
        "day": 1,
        "precision": "day",
        "display": "1949年10月1日",
        "circa": false
      },
      "level": 1,
      "tags": ["建国"],
      "region": "北京",
      "viewpoint": "",
      "sharedEventId": null,
      "links": []
    }
  ]
}
```

### 6.2 关键字段说明

| 字段 | 说明 |
| --- | --- |
| `precision` | 精度枚举：`century` / `decade` / `year` / `month` / `day` / `hour` / `minute` / `circa` / `range` |
| `date.year` | 整数年份，公元前为负数（如公元前 221 年 → `-221`） |
| `date.display` | 面向展示的文本（如「约公元前 2070 年」），缺省时自动生成 |
| `date.circa` | 是否为约数（「约」） |
| `level` | 事件等级 `1—5`，1 级为最核心 |
| `summary` | 事件描述，**上限 150 字**，超出自动截断 |
| `sharedEventId` | 跨时间轴共享标识（如二战在中/外时间轴共用 `wwii`） |
| `links` | 预留的外部关联字段，当前导出为空数组 |

### 6.3 校验与容错规则

- 缺少 `id` 或 `title` 的时间轴：拒绝导入并提示；
- 事件缺少 `title`：跳过该条并计入警告；
- 事件 `id` 重复：自动重新生成；
- 描述超 150 字：自动截断并提示；
- 单时间轴事件数超过 3000：仅保留前 3000 条并提示；
- 文件 `schemaVersion` 高于程序：按当前规范读取并提示；
- 兼容被 `{ "timeline": { ... } }` 包裹的导出文件。

## 七、编辑与导入导出规则

1. **系统内置时间轴只读**：对其执行任何编辑时，自动另存为一份用户副本（`user-原ID-时间戳`），原始内置数据不受影响。
2. **用户数据在内存中编辑**：所有改动先落在内存，**手动导出**后才会持久化为文件；页面关闭前若存在未导出的改动，会弹出提醒。
3. **导入冲突默认跳过**：当导入的时间轴 `id` 已存在时，默认跳过该条，不覆盖已有数据。
4. **导出**：单条时间轴导出为 `.json`；多条导出为 `.zip`；**当前视图导出为 `.png`**（文件名 `大事年表_视图_YYYYMMDD_HHMM.png`）。
   PNG 直接取主画布的 backing store（已按 DPR 放大）经 `toBlob` 生成，纯前端零依赖；导出内容为画布本身，不含 DOM 浮层。
5. **ZIP 实现**：零依赖、**store 模式（不压缩）**，自实现本地文件头、中央目录与 CRC32 校验，可在任意解压工具中正常打开。

## 十、浏览器要求

需要支持以下特性的现代浏览器（Chrome / Edge / Firefox / Safari 近两年版本）：

- Canvas 2D、Pointer Events
- CSS 自定义属性（CSS Variables）
- `Blob` / `URL.createObjectURL`（导出功能）
- `backdrop-filter`（浮层毛玻璃；不支持时自动回退为不透明底色）
- `Canvas.toBlob`（导出当前视图为 PNG；缺失时退化为 `toDataURL`）
- `localStorage`（视图偏好持久化；不可用时自动降级为内存存储，功能不受影响）
